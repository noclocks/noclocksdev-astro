# Codebase Review & Audit — 2026-05-23

## Scope
- Static Astro website pages, shared components, and content coherence.
- Build integrity, functional UX checks, business info completeness, and obvious accessibility gaps.

## What was audited
- Routing/pages under `src/pages`
- Shared sections/components under `src/components`
- Styling behavior for contact, FAQ, team, and testimonials pages
- Build output warnings and missing-asset issues

## Findings and actions

### 1) Missing hero image references (fixed)
Several pages referenced image assets that did not exist and produced Vite warnings in the production build.

**Fixes made**
- Updated contact hero to use an existing hero image.
- Updated testimonials hero to use an existing hero image.
- Updated FAQ hero to use an existing hero image.
- Updated team hero to use an existing hero image.

### 2) Business information completeness on Contact page (improved)
Contact page previously had minimal business metadata.

**Fixes made**
- Added explicit business information block with:
  - Primary email
  - Operating location (Atlanta, GA, US)
  - Typical response time

### 3) FAQ content consistency (fixed)
FAQ said to check business hours on Contact page, but those hours were not listed.

**Fix made**
- Reworded to align with actual contact behavior (reach out anytime, typical response within one business day).

### 4) FAQ accordion accessibility (improved)
Accordion headers did not expose expansion state to assistive tech.

**Fixes made**
- Added `aria-expanded="false"` default to accordion buttons.
- Synced `aria-expanded` state to true/false on toggle logic.

## Validation checks
- Production build succeeds with no missing-asset warnings.

## Remaining recommendations (non-blocking)
- Wire contact form submission to a backend endpoint or provider and add success/failure UX states.
- Add keyboard-focus-visible styling audit across all custom interactive controls.
- Add page-level metadata consistency review (Open Graph/Twitter tags per page).
- Introduce automated linting/a11y checks in CI (e.g., ESLint, Astro check, Pa11y/Lighthouse CI).
